# Moon Lotus Academy

Moon Lotus Academy için hazırlanmış tek sayfalık, mobil uyumlu web sitesi.

## GitHub'a yükleme

ZIP dosyasını önce telefonunda açın. GitHub'daki **Upload files** sayfasında ZIP'in içindeki dosyaları seçin:

- `index.html`
- `README.md`

Ardından **Commit changes** düğmesine basın.

## Vercel

Repository Vercel'e bağlıysa commit işleminden sonra site otomatik olarak yeniden yayınlanır.
